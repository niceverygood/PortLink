> Google Play + Apple App Store 등록용 시각·텍스트 자산 일괄 생성.
> CLAUDE.md §3(카피 톤) · §4(표기 규칙) 준수.

## 빠른 사용

```bash
npm run marketing:store
```

→ `output/google-play/`, `output/app-store/` 에 PNG 19개 + JPG 1개 생성.

카피 수정은 `generate.ts`의 `SCREENSHOTS` 배열만 손보면 즉시 재생성.

## 텍스트 자산

### Google Play

#### 짧은 설명 (80자 한도)

> 컨테이너 트럭 차주를 위한 디지털 배차. 안전운임 자동 검증, 빈 차 회송 보상까지.

#### 자세한 설명 (4000자 한도)

```
PortLink Driver — 컨테이너 트럭 차주님을 위한 배차 플랫폼

📦 안전운임 자동 검증
국토교통부고시 제2026-55호 기준으로 차주님이 받아야 할 법정 최저 안전위탁운임을
자동 계산해 드립니다. 약정 운임이 법정 최저액 미만이면 즉시 알려드리고,
신고서 양식 PDF까지 1-Click으로 다운로드할 수 있습니다.
청구 여부와 신고는 차주님이 직접 결정하시면 됩니다.

⚡ §14 공차 운행 보상 안내
직전 운송지에서 다음 운송 출발지까지 10km 이상 빈 차로 이동하셨다면,
안전운임 제14조에 따라 화주 또는 운수사업자에게 공차 보상을 청구하실 권리가 있습니다.
PortLink는 이 권리를 자동으로 알려드리고 청구서 양식을 제공합니다.
다른 주선사가 알려주지 않던 차주님의 권리, PortLink가 알려드립니다.

🚚 가까운 배차부터 정렬
현재 위치에서 가까운 OPEN 배차를 거리순으로 보여드립니다.
운송 완료 직후 가까운 다음 배차를 추천해 빈 차로 돌아가는 거리를 줄여드립니다.

📍 위치 정보 안전 정책
백그라운드 GPS 추적은 하지 않습니다.
출발·상차·하차·완료 액션을 누르는 그 순간만 좌표 1회를 기록합니다.
위치 권한을 거부하셔도 모든 기능은 정상 작동합니다.

💰 깨끗한 정산
- 플랫폼 수수료 5% (런칭 기준)
- KRW 정수 단위, 소수점 없음
- 안전운임 한도 미달 입력 강제 차단
- 정산 명세 한눈에 확인

🎯 PortLink의 약속
- 광고비 받은 배차 우선 노출 안 합니다
- 차주님 이익 기준으로만 추천합니다
- 자동 청구·자동 신고는 절대 하지 않습니다 — 양식만 제공
- 차주님 자율성을 침해하지 않습니다

면책 고지
신고 여부와 신고 내용에 대한 책임은 차주님 본인에게 있으며, PortLink는
신고 결과 및 §14 보상 청구 결과에 대해 어떠한 법적 책임도 부담하지 않습니다.
```

## Wrap (PWA → Native) 권장 도구

본 자산은 PWA 화면을 mock으로 재현한 것입니다. 실제 스토어 등록을 위해서는
PWA를 네이티브 앱으로 wrap해야 합니다 (Apple은 PWA-only 등록 거부).

**Capacitor 권장**:

```bash
npm i -D @capacitor/cli
npx cap init "PortLink Driver" "kr.portlink.driver"
npx cap add ios
npx cap add android
```

- iOS는 macOS + Xcode 필요
- Android는 Android Studio 필요
- Capacitor는 push 알림 native API 제공 (PWA 한계 해결)

## 자산 재생성 시 주의

- `_shared.css`의 색상 토큰 변경 시 모든 자산이 일관되게 갱신됨
- Pretendard 폰트는 jsdelivr CDN에서 로드 — 오프라인 환경에서는 로컬 woff2로 교체 필요
- Puppeteer chromium은 `$HOME/.cache/puppeteer/`에 설치됨 (커밋 X)
- 결과물 PNG/JPG는 `git lfs` 없이 일반 커밋
